# The Super Puff Lab

A concept by Isabella Linde: an interactive, single-screen "digital poster" for exploring The Super Puff™ and its variants. Not affiliated with Aritzia.

Built with Vite, TypeScript and Three.js. The jacket is generated procedurally in code (no imported model), so length, fit, sleeves and fabric are real geometry and material changes.

```sh
npm install
npm run dev     # local dev server
npm run build   # typecheck + production build
```

See `SPEC.md` for the full design spec.
